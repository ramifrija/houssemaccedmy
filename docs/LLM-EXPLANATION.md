# Why use two LLMs (Mistral and Llama)?

We use two AI models together like a team:

1. **Mistral**: It is fast and cheap. We use it for simple questions.
2. **Llama**: It is smarter and more powerful, and it uses the GPU to run. We use it for hard problems.

**Why?** Using both saves money, keeps the app fast, and gives us a backup if one breaks!
