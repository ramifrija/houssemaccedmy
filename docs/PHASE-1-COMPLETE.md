## 🛠️ Commandes Disponibles

### **Build et Déploiement**
```bash
npm run build:prod          # Build de production
npm run build:mobile        # Build + sync Capacitor
npm run deploy:mobile       # Déploiement complet
```

### **Plateformes**
```bash
npm run cap:ios             # Ouvrir Xcode
npm run cap:android         # Ouvrir Android Studio
npm run cap:sync            # Synchroniser Capacitor
```

### **Développement**
```bash
npm run dev                 # Mode développement
npm run lint                # Vérification du code
npm run preview             # Prévisualisation
```
