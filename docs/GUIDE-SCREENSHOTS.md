# 📸 GUIDE CRÉATION SCREENSHOTS POUR GOOGLE PLAY

## 🎯 MÉTHODE SIMPLE : UTILISER VOTRE NAVIGATEUR

### ÉTAPE 1 : OUVRIR L'APPLICATION
1. Ouvrez Chrome ou Edge
2. Allez sur : http://localhost:8082/
3. Connectez-vous avec un compte Supabase de test (credentials gérés dans le dashboard Supabase)

### ÉTAPE 2 : ACTIVER LE MODE MOBILE
1. Appuyez sur **F12** (outils développeur)
2. Cliquez sur l'icône **📱 mobile** en haut à gauche
3. Sélectionnez : **Galaxy S20 Ultra** (1440 x 3200)

### ÉTAPE 3 : PRENDRE LES SCREENSHOTS

#### Screenshot 1 - Page de connexion
1. Déconnectez-vous si connecté
2. Allez sur la page de connexion
3. Appuyez sur **Ctrl + Shift + S** (screenshot)
4. Sauvegardez : `screenshot-1-login.png`

#### Screenshot 2 - Dashboard
1. Connectez-vous
2. Sur la page dashboard
3. Appuyez sur **Ctrl + Shift + S**
4. Sauvegardez : `screenshot-2-dashboard.png`

#### Screenshot 3 - Calendrier
1. Cliquez sur "Calendrier" dans le menu
2. Appuyez sur **Ctrl + Shift + S**
3. Sauvegardez : `screenshot-3-calendar.png`

#### Screenshot 4 - Présences
1. Cliquez sur "Présences"
2. Appuyez sur **Ctrl + Shift + S**
3. Sauvegardez : `screenshot-4-attendance.png`

#### Screenshot 5 - Messagerie
1. Cliquez sur "Messagerie"
2. Appuyez sur **Ctrl + Shift + S**
3. Sauvegardez : `screenshot-5-messaging.png`

### ÉTAPE 4 : REDIMENSIONNER (SI NÉCESSAIRE)
1. Allez sur : https://www.iloveimg.com/resize-image
2. Uploadez vos screenshots
3. Redimensionnez à : **1080 x 1920 pixels**
4. Téléchargez

### ÉTAPE 5 : UPLOADER SUR GOOGLE PLAY
1. Dans Google Play Console
2. Section "Captures d'écran"
3. Cliquez sur "Ajouter des images"
4. Sélectionnez vos 5 screenshots
5. Enregistrez
