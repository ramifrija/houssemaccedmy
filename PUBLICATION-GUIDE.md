## 📱 PUBLICATION APP STORE (iOS)

### **Étape 1 : App Store Connect**
1. **Aller sur** : https://appstoreconnect.apple.com
2. **Se connecter** avec votre Apple ID développeur
3. **Cliquer** sur "Mes Apps" → "+" → "Nouvelle App"

### **Étape 2 : Informations de Base**
```
Nom de l'app : Houssem Academy
Langue principale : Français
Bundle ID : com.houssemacademy.app
SKU : houssem-academy-001
Type : App
Catégorie principale : Education
Catégorie secondaire : Productivity
```

### **Étape 3 : Télécharger le Build**
1. **Aller** dans l'onglet "TestFlight" ou "App Store"
2. **Cliquer** sur "+" pour ajouter une nouvelle version
3. **Télécharger** le fichier : `ios/build/App.ipa`
4. **Attendre** le traitement (5-10 minutes)

### **Étape 4 : Métadonnées**
```
Nom : Houssem Academy
Sous-titre : Gestion académique moderne
Description : Houssem Academy révolutionne la gestion académique avec une interface moderne et intuitive. Développée pour les établissements scolaires, cette application offre tous les outils nécessaires pour une gestion efficace et transparente.

Fonctionnalités principales :
• Dashboard interactif avec métriques temps réel
• Marquage des présences par QR code
• Planification et suivi des cours
• Communication intégrée
• Analytics et rapports détaillés
• Sécurité renforcée
• Design responsive

Mots-clés : education, school, management, attendance, calendar, messaging, reports
URL de support : https://houssemacademy.com/support
URL marketing : https://houssemacademy.com
URL de confidentialité : https://houssemacademy.com/privacy
```

### **Étape 5 : Assets**
1. **Icône** : Télécharger `assets/store-assets/icons/ios/icon-1024.png`
2. **Captures d'écran** : 
   - iPhone 6.7" : 1290x2796px (3-10 images)
   - iPhone 6.5" : 1242x2688px (3-10 images)
   - iPhone 5.5" : 1242x2208px (3-10 images)
   - iPad 12.9" : 2048x2732px (3-10 images)
   - iPad 11" : 1668x2388px (3-10 images)

### **Étape 6 : Soumettre pour Review**
1. **Remplir** toutes les métadonnées
2. **Vérifier** que le build est traité
3. **Cliquer** sur "Soumettre pour review"
4. **Attendre** l'approbation Apple (24-48h)
