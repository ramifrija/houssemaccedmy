## 📱 ACCÈS DEPUIS UN AUTRE APPAREIL

Pour accéder au dashboard depuis un téléphone ou tablette sur le même réseau WiFi :

1. **Trouver votre IP locale :**
   ```powershell
   ipconfig
   # Chercher "IPv4 Address" (ex: 192.168.1.100)
   ```

2. **Démarrer le serveur :**
   ```bash
   npm run dashboard
   ```

3. **Accéder depuis l'autre appareil :**
   ```
   http://[VOTRE_IP]:3000
   ```
   Exemple : http://192.168.1.100:3000
